# Furniture-ERP

Stock, sales, payments and customer credit system for an office furniture importer
(Piassa, Denbel, Pawlos), with a Telegram bot.

- `userequirements.md` — the client's requirements
- `BUILD_PHASES.md` — what to build, phase by phase, and the decisions taken from the requirements
- `FOLDER_STRUCTURE.md` — where each file lives
- `backend/` — Django REST API, Celery jobs and the bot ([backend/README.md](backend/README.md))

Branches: `Back-End` is the working branch for the backend; `main` is production.
